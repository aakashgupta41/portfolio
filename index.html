RAG-Based Intelligent Document Chatbot

● In progress

A chatbot that answers questions from your own PDF, DOCX and Excel files. Instead of guessing, it retrieves the most relevant passages first and gives them to the LLM as context.

  1. Load documents
  2. Split into chunks
  3. Create embeddings
  4. Search FAISS
  5. LLM answers
  • Handles multiple file formats: PDF, DOCX and Excel
  • Semantic search with a FAISS vector store and HuggingFace embeddings
  • Switches between LLM providers (OpenAI, Groq) through LangChain
  • Text chunking and dynamic retrieval tuned for relevant answers
